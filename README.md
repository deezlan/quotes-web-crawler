# COMP3011 Search Engine

A command-line search engine that crawls [quotes.toscrape.com](https://quotes.toscrape.com/), builds an inverted index, and supports search queries.

## Setup

```bash
# Clone the repository
git clone https://github.com/<your-username>/quotes-web-crawler.git
cd quotes-web-crawler

# Create and activate a virtual environment
python -m venv venv
source venv/activate        # Mac/Linux
venv\Scripts\activate       # Windows

# Install dependencies
pip install -r requirements.txt
```

## Usage

```bash
python -m src.main
```

### Commands

| Command | Description |
|---|---|
| `build` | Crawl the website and build the index |
| `load` | Load a previously built index from disk |
| `print <word>` | Print the index entry for a word |
| `find <word(s)>` | Find all pages containing the search terms |
| `help` | List all available commands |
| `quit` | Exit the shell |

### Examples

**Build the index:**
```
> build
[crawler] Fetching: https://quotes.toscrape.com
[crawler] Waiting 6s...
...
[shell] Index built with 1423 unique words.
```

**Load a previously built index:**
```
> load
[indexer] Index loaded from data/index.json
[shell] Index loaded with 1423 unique words.
```

**Print index entry for a word:**
```
> print love
Index entries for 'love':
  https://quotes.toscrape.com/
    Frequency : 3
    Positions : [12, 47, 203]
```

**Find pages matching a multi-word query:**
```
> find good friends
Pages matching 'good friends':
  https://quotes.toscrape.com/page/3/
  https://quotes.toscrape.com/tag/friendship/
```

**Word not in index:**
```
> print notaword
[search] 'notaword' not found in index.
```

**Missing argument:**
```
> find
[shell] Usage: find <query>
```

## Dependencies

- `requests` — HTTP requests for crawling
- `beautifulsoup4` — HTML parsing
- `pytest` — test runner

## Notes

- The `build` command observes a 6-second politeness window between requests — crawling the full site takes several minutes
- Run `build` once to generate `data/index.json`, then use `load` for subsequent sessions
- Search is case-insensitive — `find Love` and `find love` return the same results
- Multi-word `find` queries use AND logic — all words must appear on the page
